🔒 API Keys & Security

Why do we need your API Key?
This dashboard interacts directly with Torn's official API to load your stats and active faction rosters in real time.

Limited vs. Full Access Keys:

  • Limited Access: Recommended for daily dashboard use. Allows reading basic stats and faction info safely.
  • Full Access: Required only if accessing restricted private data or managing faction administration.

Trust Notice: Since this site is hosted statically on GitHub Pages, no server stores your key. You can inspect the source code anytime to verify privacy.
